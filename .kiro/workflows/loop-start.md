# Loop Start: Discover the Problem

1. Inspect the repository, recent changes, relevant docs, and tests.
2. Restate the user problem and desired outcome without prescribing a solution too early.
3. Identify current behavior, constraints, affected users, dependencies, and unknowns.
4. List assumptions and distinguish verified facts from hypotheses.
5. Ask concise questions for decisions that block a sound plan; otherwise state safe assumptions explicitly.
6. Produce a short discovery brief with problem, goals, non-goals, constraints, risks, and success measures.
7. Do not implement until the next planning/specification stage is ready or the user explicitly asks for a direct fix.
